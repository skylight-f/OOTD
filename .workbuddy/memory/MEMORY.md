# OOTD 穿搭助手 - 项目记忆

## 架构决策

- **数据存储**：第一版使用纯本地数据（wx.setStorageSync），待功能成熟后再接入后端。storage.ts 已做接口抽象，切后端时只需改这一层。
- **天气服务**：和风天气（QWeather），无 API Key 时自动用 Mock 数据。API Key 填入 `src/utils/weather.ts` 的 `QWEATHER_KEY` 常量即可切换。
- **技术栈**：Mpx + TypeScript + Less，严格模式。使用路径别名 `@/` 指向 `src/`。
- **UI 风格**：各页面有独立视觉风格——首页暖杏色背景，衣橱大地色系，添加页白色卡片红主题，搭配页白色卡片红点缀。
- **编码规范**：PascalCase 文件名，camelCase 文件夹；用 less 不用 stylus；修改后不要执行 build。
